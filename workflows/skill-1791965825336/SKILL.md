# 市民外购资产筛选

停自研深挖后，用统一清单筛可商用、可贴风格、可进引擎的角色资产。候选只交清单，**用户拍板才采购**。

## 适用
- 从 CGTrader / ArtStation / Sketchfab / Unity Store / Fab 等找市民候选
- 核可商用许可、格式、LOD、绑定与自研引擎导入风险

## 风格硬筛（本项目）
- 大陆青年东亚骨相；暖中性肤色
- 日常都市（优先便装/夹克；少正装领带）
- 写实、能对中端卡预算（近景细 / 远景减面）

## 预算（硬）
- **上限人民币 ¥10**（不是美元）。超 ¥10 **一律不进短名单**
- 优先免费；免费包常缺原生 glTF / 三档蒙皮 LOD / 对齐骨架 → 导入成本多半标「高」，须在卡上写明
- 许可 Warn / Fail 的不采购，哪怕免费

## 技术硬筛
- **格式：** 优先已绑定 + 多 LOD + 可商用 glTF/GLB（兼 FBX 更佳）
- **引擎终态：** 商店 glTF/FBX **不能**直进共享静态度导入（拒骨骼/动画）。必须走 `citizen_engine_export_v01` → `assets/citizens/<id>` + `Citizens.h`（自定义蒙皮二进制：三档 LOD + anim.bin）
- **导出约束（程序定版）：** 骨架名对齐现有 clip；权重 ≤4 骨/顶点；三档蒙皮 LOD；材质尽量可拆 body/hair/brow；顶点数/LOD 勿超 u16
- **常见坑：** Mixamo/UE 骨架要对齐；动画重烘焙进 anim.bin；贴图再套 `T_Citizen_M01_<Slot>_LOD#`（BaseColor/Normal/ORM）
- **导入成本粗标：** 自带 3 LOD+绑定 → 低/中；有绑定无 LOD → 中高；仅静态度/骨架不对 → 高

## 许可硬筛
| 字段 | 内容 |
| --- | --- |
| 名称 / URL | |
| 价格（¥） | 免费 / ≤¥10；超价不列 |
| 许可名 | royalty-free commercial / … |
| 商用 / 改模 / 再分发 | Y/N |
| 署名要求 | Y/N |
| 判决 | Pass / Warn / Fail |

Fail 不出短名单。Warn 可展示但**禁止下单**直至核清或用户明示接受。

## 候选卡模板（单一表交给 Ari → 用户）
建模维护唯一表，美术过脸，程序补导入列，合成 **一张** 短名单（2–4 条）：
1. 链接 + 价（¥）+ 许可判决
2. 美术：脸型/服装一句
3. 格式 / 三角数 / LOD / 绑定
4. 程序：进 `citizen_engine_export` 成本（低/中/高）
5. 推荐角色（主推 / 备选 / 仅多样性）

用户未定前不采购、不进引擎主线。

## 分工
- 建模：搜链 + 技术字段 + 唯一合成表
- 美术：脸型剪影与服装
- 程序：导入成本列
- Ari：转用户拍板
- skill管理：维护本清单
