# 模型交付门禁

通用交付前自检。**不合格禁止交付**。几何干净只是入场券，穿模过了不等于可交付。

- 角色白模比例/剪影：先过 [市民白模三视图门禁](sand-workflow:skill-1791962320249)，再叠本门禁。
- 城市建筑完整建模流程（kit 原语、拆件、总装、十六项闸门）：项目包 `city-building-modeling`（团队库与 `/workspace/city-building-modeling-v2/city-building-modeling/`）。本门禁只收其中通用的验收规则，不复制建模步骤。

## 第零关：数字自洽（动工/交付前）
1. **加和闭合：** 凡写成「A + B + C = 总高/总长」的数，逐条复算；矛盾时以有设计依据的为准改另一个。
2. **锁定文档与生成器一致：** 层高、标高、洞口、间距等常量逐项对照 lock；不一致由 lock 拥有者决定改哪边，不能各说各的。
3. 每次修订记变更：日期、版本、决定人、旧值→新值、理由。

例：屋面 18.45 + 机房 3.0 + 压顶 0.45 = 21.9，却写总高 22.9 → 机房改 4.0。

## 第一关：几何干净（全过才进第二关）
- [ ] 无穿模（部件互穿、楼板穿外墙、构件插进墙体、立管刺穿走道）
- [ ] 无飞面、半透碎面、零面积面、共面重叠（转角/窗角出现黑点黑块多半是共面重叠）
- [ ] 外轮廓闭合；文字等开放边要加厚封口
- [ ] 窗洞/门洞不穿墙，开洞有墙厚
- [ ] 法线正确，无黑面；材质不偏暗（覆盖在项目侧，不改共享 kit）
- [ ] 尺度 1u=1m，落地 Z=0，枢轴按约定；文字已转网格，实例化不丢件

## 第二关：细节完整度（对照真实参考图）
按远/中/近三档核对，缺档不交：
- **远景（体量轮廓）：** 层高与开间模数、转角加宽、女儿墙+压顶、勒脚、出屋面楼梯间/机房、屋顶设备；山墙/屋顶无大块空白。
- **中景（立面层次）：** 腰线/檐口线脚；窗做到「洞口→套→台」三层，窗后有深色室内体量不透空；落水管带雨水斗、鹅颈和管卡且只在转角/合理柱距；空调机位；入口雨棚+台阶+坡道栏杆；窗型不过度重复；分缝、勒脚到位。
- **近景（特写）：** 转角板件不变形；雨棚底吊顶+滴水线；壁灯、门框拉手、避雷带；栏杆完整。
- **总规则：** 出挑在 0.06–0.26 m，不出现 0 厚度贴片；重复构件按固定间距循环，不手摆。
- 风格符合 Brief（建筑锁中国大陆城市语汇，禁欧式城堡等）；预算近景细、远景交 LOD，满足中端卡 1080p。

### 小件真实原型与安装逻辑（user-1214）
细节 ≠ 件数多。交审前每个小件（灯、牌、管、机、把手、读卡器、雨棚、装饰件等）须能回答三问，答不上来就**删掉或重做**；结果写入 QC「小件审计表」：
1. 现实中是什么（具体产品/构件名）？
2. 怎么固定（底板、螺栓、管卡、支架、夹具、焊接、嵌入）？
3. 连到哪里（墙、柱、门框、地面、排水、电源、另一构件）？不能悬空、不能乱贴在玻璃上、不能半截插进别的东西。

做法：小件写成带安装件的函数/完整构件，禁止随手占位方块代替。六则建筑反例见包 `city-building-modeling` §四.16。

每条不过写**具体位置+问题**，不写「感觉还行」。

## 第三关：出证视图
交付包必须含：
1. **角透视**（45° 左右，看两个立面+屋顶）
2. **正视**（主立面正交）
3. **近景特写**（转角、入口、窗/栏杆至少一处）
4. 并排**真实参考图**
5. 自检结果（第零~二关逐条勾选，含小件审计表）+ 三角面数

渲染背景用干净天空，不露 HDRI 楼群；高耸部件全身入画，不切顶切脚。缺任一视图不送验。

## 流程
1. 建模自检第零、一关 → 不过自己打回
2. 自检第二关（含小件三问），对照参考图 → 不过自己打回
3. 出第三关视图包
4. 美术签风格/细节 → Ari 转用户
5. 用户打回则记教训，回到对应关修

## 常见翻车
- 只查穿模就交 → 用户嫌细节空、像方盒子
- 小件用灰盒/悬空板凑数 → 答不出「是什么/怎么固定/连哪」被打回
- 只交正视 → 看不出转角与屋顶问题
- 无参考图对照 → 构件缺漏没人发现
- 一种窗复制全楼 → 失真
- lock 和生成器数字各写各的 → 返工
