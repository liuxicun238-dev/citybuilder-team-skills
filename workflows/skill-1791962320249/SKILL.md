# 市民白模三视图门禁

用**可测量的正侧对照**过白模关，禁止凭视口感觉过关。过关前不做骨架、不做材质。

## 适用
- 角色白模 / 象形白模比例与剪影验收
- 用户或制作判定「不像三视图」需要重做
- 需要复现的 Blender 参考图摆放与对照渲染

## 硬规则（团队已定）
1. 分步：① 白模正侧 → ② 用户过关 → ③ 骨架 → ④ 材质。禁止一次做到底。
2. **官方正交三视图**管比例与外轮廓；概念透视只参考细节，不锁尺。
3. 美术可签头身/剪影，但**用户拍板才过关**；美术签了用户仍可否决。
4. 过关前骨架、贴图、ORM 一律冻结。
5. 送验必须带**正侧图 + 叠图 + 百分比偏差表**；缺一不送验。叠不上建模先自打回。

## 门禁步骤
1. **裁切参考：** 把官方三视图拆成 `ref/front.png`、`ref/side.png`（同比例、同地平线；擦掉标尺/文字等模型不含的像素）。
2. **校准场景：** Blender 1u=1m，脚底 Z=0，角色朝 -Y；正/侧参考图作为 Empty 或背景，缩放到目标身高（市民男款约 1.72–1.75m）。
3. **只做象形块面：** 头、躯干、夹克外轮廓、裤型、背包体量等主块；不雕毛孔、不上色。服装/背包与身体分件更清晰。
4. **同相机出证：** 正视/侧视正交渲染白模（无贴图），与参考叠图对照。写**可测偏差**，别写形容词：
   - 头高、肩宽、夹克下摆、背包厚度、裤腿外轮廓、侧面胸腹深度相对参考差百分之几
   - 可选：剪影 IoU（blockout ≥0.85；forms ≥0.90）；正交片用世界坐标门禁，避免只靠包围盒对齐掩盖身高/轴偏
5. **交付验收包：** 正面图、侧面图、叠图、身高与三角数、本轮相对三视图的**百分比偏差表**（至少含夹克轮廓、裤型、背包侧面体量、袖臂/肩宽、侧面胸腹）。
6. **过关判定：** 美术先签头身剪影 → 制作转用户 → 用户过关后才开骨架。未过关则改常数/块面重渲，不进入下一阶段。

## 本项目检查清单（男款）
- 头身 ≈ 7.5（约 7.3–7.6 可谈）
- 牛仔蓝夹克外轮廓对齐三视图
- 米灰裤型对齐（勿圆柱腿）
- 墨绿背包体量（侧面勿过鼓）
- 袖臂/肩宽勿偏宽；侧面胸腹勿偏厚也勿过瘦（改厚时别矫枉过正）
- 近景可细、远景留给 LOD（白模阶段只锁剪影可读性）

## 常见翻车
- 参考图透视当正交用 → 剪影永远对不齐
- 只交灰模意向图、没有与三视图同机位对照 → 验收无效
- 有图无百分比偏差表 → 打回补表
- 白模未过就绑骨/上材质 → 返工成本倍增
- 用「感觉差不多」代替百分比/叠图 → 用户仍会判不过
- 修厚改瘦矫枉过正（腿/胸深偏细）→ 对照参考百分比回调
