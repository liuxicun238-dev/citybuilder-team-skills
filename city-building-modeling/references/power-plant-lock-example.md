## A0 参考审视（永久决定）
| 元素 | 决定 | 理由 |
|---|---|---|
| 长主厂房（浅灰竖肋压型钢板墙、蓝色横带、带形窗、低坡双坡屋面） | 采用 | 与真实燃机电厂主厂房一致，是最显眼特征 |
| 山墙蓝色斜带 | 采用 | 参考可见，工业建筑常见做法，增加识别度 |
| 厂房正面 6 个散落小方盒 | 修改 | 数量碎、无功能。改为：每台燃机一座**进气过滤室**（钢架托起、正面成排防雨百叶、风道接入厂房）+ 两座单层**电气附房**；仍保留“厂房前一排方体”的外观 |
| 两台余热锅炉、各带一根钢烟囱、外楼梯和多层平台（黄色栏杆） | 采用 | 真实一机一炉一烟囱 |
| 两台锅炉的烟囱位置不一致（一个在侧面、一个在前部） | 修改 | 烟气从燃机排出→锅炉入口（靠厂房）→出口（远端）→烟囱。两台统一：入口过渡烟道接厂房后墙，烟囱在远离厂房的一端 |
| 锅炉入口和厂房之间看不到连接 | 修改 | 加扩散段排气烟道（燃机排气→锅炉），否则不合实物逻辑 |
| 四风机机力通风冷却塔（混凝土塔体、进风口、风筒、平台蓝色栏杆、端部门和雨棚、管桥接厂房） | 采用 | 真实；管桥跨路接汽机房一端（凝汽器循环水） |
| 调压站（黄色燃气管、单独围栏、棚子） | 采用 | 中国燃气管道刷黄色，与真实一致；补一条黄色燃气管廊从调压站接到燃机 |
| 主变压器在厂房右端 | 采用 | 发电机→主变→开关站。三台：燃机两台+汽机一台，中间加防火墙 |
| 两处开关设备（锅炉右后一片、门口右侧一片） | 修改 | 合并为一座开关站（门口右侧那片，参考里最清楚），出线塔挪到开关站外侧，电线不跨厂区 |
| 出线铁塔 | 修改 | 作为可选部件（游戏有自己的电网连线时可以不摆），资产只留出线构架和接线点 |
| 门口：电动推拉门 + 岗亭在门旁围墙线上 + 人行小门 | 采用 | 符合公安局教训：一个入口一种拦截方式，岗亭在墙线上 |
| 办公/集控楼 4 层 + 门前停车 + 草坪 | 采用 | 门面区在大门旁，停车靠楼前 |
| 大门右侧整块草坪、门口两片绿地 | 修改 | 绿化克制：前围墙内一排树、办公楼周围草坪；其余为铺装/预留空地（公安局、医院绿化过头的教训） |
| 实心水泥板围墙 + 墙垛 | 采用 | 电厂常见 |

## 结构读取（各部件）
- 主厂房：一层通高大厅；外墙底部约 1.2 m 混凝土勒脚，上为竖肋压型钢板；两条带形窗（下层约 5–7 m，上层紧贴蓝带下沿）；蓝带约 1.6 m 高、绕四面，山墙上蓝带沿斜线上升；屋面直立锁边、檐口有包边/天沟，屋脊有通风器；山墙有大型卷帘设备门。
- 余热锅炉：长方体护板箱体（竖向加劲肋），四周钢柱；顶上有汽包小房；侧面之字形楼梯塔，多层格栅平台带黄色栏杆；烟囱是钢筒（横向加强环）、顶部平台和外爬梯；锅炉之间有泵、管道、卧式罐。
- 冷却塔：4 格一排，混凝土框架，两长边下部为进风口（立柱+百叶），上部实墙，屋面风机平台带栏杆，风筒为短圆筒（上口外翻），筒内可见风机叶片；端部有门和雨棚；侧面钢梯。
- 调压站：混凝土地坪、黄色栏杆围栏；过滤器（立式罐）、计量和调压管路成排平行，阀门、法兰；轻钢双坡棚（开敞）。
- 主变/开关站：主变 = 油箱 + 两侧散热器片 + 储油柜 + 高压套管；开关站 = 碎石地面、门型构架、断路器、隔离开关、互感器、避雷器、管母线。
- 办公楼：4 层，规则开窗、竖向壁柱、女儿墙；屋顶两个楼梯/机房小间；入口平顶雨棚两柱 + 台阶。
- 门卫：平顶小屋、宽檐口、带形窗；电动推拉门（竖向栅条）；方形门垛。

## 材质真值表
- 彩钢压型板（墙/屋面）：浅灰白 (0.72,0.73,0.74)，涂层钢板，粗糙度 .45，竖肋几何表达，不做锈。
- 蓝带：工业蓝 (0.03,0.18,0.55)，同一涂层。
- 锅炉护板/烟囱：浅中灰镀锌/涂装钢 (0.48,0.50,0.52)，粗糙度 .5，金属感弱（涂装），烟囱顶略暗。
- 栏杆/梯子：安全黄 (0.85,0.62,0.05) 涂装，粗糙度 .5；冷却塔栏杆为蓝色（参考）。
- 燃气管：中黄 (0.86,0.66,0.08)；其他工艺管：浅灰/银灰。
- 混凝土：浅灰 (0.55,0.55,0.53)，粗糙度 .85。
- 变压器：灰绿/中灰涂装 (0.36,0.40,0.38)，套管为棕色瓷或灰色硅橡胶。
- 沥青 (0.06,0.065,0.07) 粗糙 .92；碎石浅灰杂色；标线白/黄不发光。
- 玻璃：蓝灰反射。
干净、维护良好，不做脏旧（与城市其他建筑一致）。
