# 完整人物建模：外部 agent 版

本包不需要原项目、原会话、API密钥、下载人体或ZBrush。代码与二维参考随包提供，不包含已建好的OBJ/BLEND/FBX。

## 先区分任务

- **固定配方重建**：从代码和参考重新计算这名成年男性白模。阅读[运行与资源](references/recipe.md)，使用scripts/run_recipe.py。这能测试独立执行和复现，不证明新角色泛化。
- **新人物制作**：阅读[完整方法](references/workflow.md)，根据用户参考重新定标、构造和修形。附带代码只能作为方法范例；不要原样跑固定配方后声称完成另一张脸/体型。

两种任务都要实际完成制作、自查并交付可编辑模型。先识别用户要哪一种，不明确时在报告中说明所选范围，不能暗中扩大成功结论。

## 工作原则

1. 从零自建几何，不能导入现成人物成品或生成3D底模替代。代码中的曲线、体积和接口可复用，但人物比例、关节点和保护域需按参考确定。
2. 参考单图单视角，白模/中性表情/一致身份。已有参考不重复生图。区分观察、测量和假设；本包头侧图并非校验后的正交扫描，身体尺寸是设计假设。不同人物需要新的全身正侧背和手足参考。
3. 按[完整方法](references/workflow.md)推进头部、眼鼻嘴耳、下巴颌颈、肩胸、双臂手掌、腹腰背、骨盆腿脚，再全身检查。已认可部位采用局部保护，不能整体重生成抹掉收益。头颈连接详见[head-neck.md](references/head-neck.md)，耳朵详见[ear-workflow.md](references/ear-workflow.md)，手部、手指骨与行走手姿详见[hands.md](references/hands.md)。
4. 全程Blender后台`-b`。不弹窗口、不抢焦点；使用用户指定工作盘。外部机器不强制G盘，运行命令显式指定输出与Blender。新运行使用空目录，禁止覆盖他人文件。
5. 基础形体先于毛孔/纹理。每轮实际看正侧斜背与局部，动画看接触、经过、摆动阶段。两轮同一问题没有可见改善，改表达或连接方法，不堆版本和细分。
6. 拓扑指标、外观、用户认可、游戏交付分别记录。零非流形不等于合格人体；闭口面不等于口腔；组件交叠不等于焊接；能播放不等于自然步态。已知限制见[检查与边界](references/validation.md)。

## 输出要求

交付全身可编辑模型、实际四视图及头手足近景、如任务需要则行走动画，记录参考来源、步骤、依赖、单位、几何检查和剩余问题。生成参考不能冒充模型渲染。代码跑完必须继续实际看图并判断；不要自动写“外观通过”。

本包方法用于完整白模原型。低模重拓扑、UV/贴图、头发衣物、手指/脸部控制、口腔牙舌、LOD与引擎接入不是已实现能力。用户要求这些时需实际制作，而非靠改交付名称宣称完成。

## 门槛补充（v01-hands）

- 头部先行：尽早取得一致的正交正/侧参考并做雕刻级修形；头部未通过并排对比前不做身体、服装、绑定。参数推形+平滑约3轮即平台期，体素重建会破坏已有蒙皮。
- 手部门槛：五指分离、指节、指甲、掌垫、大鱼际、虎口、拇指对掌角、腕-袖口过渡；尺寸对照真实参考（记录来源与许可）。
- 手指骨每指3节含拇指，LOD1/2可并入掌骨，每顶点≤4权重；行走手放松半握、手腕跟随滞后、手与裤/腿零接触并给出间隙数值。
- 必交：张开/半握掌背近景、真实手并排图、行走手部gif。已知待补：服装褶皱与拉链、滑步、背包二级运动、纯色材质。
