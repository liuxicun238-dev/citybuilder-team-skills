# 手部建模、手指骨骼与行走手姿

本文件补充[完整方法](workflow.md)第4节，来自citizen-skill-v01-run（2026-10-16）手部返工的教训。手部不合格时不得进入绑定/行走验收。

## 1. 建模门槛（逐项检查，缺一项即不通过）

- 五指分离：四指+拇指各自独立，指间在指根以外有可见间隙；不得是“桨状/连指手套”。
- 指节：掌骨头（背侧指节隆起）及PIP/DIP关节轻微增宽。
- 指甲：远节背侧有指甲板与甲襞沟，拇指同样有。
- 掌部体积：远侧掌垫、小鱼际、掌心凹陷；不能是平板。
- 大鱼际（thenar eminence）：拇指根部明显肌肉体积。
- 虎口（thumb-web）：拇指与食指掌骨之间的连续蹼，不是两根圆柱硬接。
- 拇指对掌角：拇指轴向掌侧旋前并偏向桡侧（参考值：掌骨轴约向掌侧35–45°、远离食指约30–40°），指甲朝向桡背侧而非与四指同向。
- 腕到袖口过渡：腕部椭圆截面连续收窄进入袖口，隐藏端深入袖内≥5cm，并与袖内壁保留间隙；行走全帧不得穿袖。

## 2. 尺寸必须对照真实参考

- 使用真实人体数据或许可明确（CC0/CC-BY/公有领域）的真实手照片，记录来源URL与许可。
- 推荐数据：ANSUR II（美国陆军2012，公有领域）。按角色身高取子样本。例：1.70–1.76m男性（n=1337）手长191.0±7.5mm、手宽87.7±3.8mm、掌长115.1±4.9mm、腕围174.7±7.6mm。
- 报告实测：手长（腕横纹→中指尖）、手宽（掌骨处）、各指长度比例（中指>环指≥食指>小指，拇指尖约达食指掌指关节）。
- 交付实拍对照并排图（同一视角：手背/手掌），图注写明来源与许可。

## 3. 手指骨骼规格

- 每指3节骨（含拇指：掌骨/近节/远节或CMC→MCP→IP→尖），双手共30根，挂在hand骨下，所有LOD共用同一骨架。
- LOD0使用独立手指权重；LOD1/LOD2可将手指权重合并到palm/hand骨（需在报告注明LOD是否保留手指弯曲）。
- 每顶点最多4个权重，权重和归一（报告最小/最大和）。

## 4. 行走中的手

- 手放松半握：四指MCP/PIP/DIP各自轻微弯曲且各指略有差异，拇指轻贴食指侧；不得僵直张开。
- 手腕随摆臂旋转，相位滞后（follow-through，约2–4帧）。
- 全帧检查：手与裤子/大腿零交叉（三角形相交测试），并报告最小间隙数值（mm）。

## 5. 必交图像

- 手掌与手背近景，各含张开与半握两种姿态。
- 与真实手参考的并排对比图。
