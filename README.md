# 城建游戏团队 Skill 库

私人仓库，存放城建游戏团队的可复用 skill。

## 目录
- `city-building-modeling/`：城市与工业建筑分件参数化建模（v2，十六项自查闸门；含第 15 项细节预算、第 16 项小件真实原型与安装逻辑，见 CHANGELOG-2026-10-16.md）
- `character-modeling-skill-v01/`：人物/市民建模 skill（当前版，后续更新）
- `workflows/`：通用 skill
  - `workflows/skill-1791962320249/`：**市民白模三视图门禁**，当角色/市民白模要对齐官方正侧三视图、做象形白模验收或用户说「不像三视图」时使用；骨架与材质过关前一律冻结。
  - `workflows/skill-1791965825336/`：**市民外购资产筛选**，当市民/角色停自研改筛网上可复用资产、做商店候选、核许可与引擎导入兼容时使用。
  - `workflows/skill-1791967319019/`：**模型交付门禁**，任何建筑/道具/角色模型转交制作或用户验收前使用：数字自洽、几何干净、远中近细节、规定视图。
  - `workflows/skill-2/`：**skill 管控**，当需要盘点、审核、更新、下线或在群里分发 skill，以及处理 skill 冲突与重复时使用。
  - `workflows/skill/`：**流程转 skill**，当有可复用的多步工作流程、操作规范或踩坑经验，需要收成通用 skill 时使用。

上传前已扫描密钥与个人信息，未包含大于 50MB 的文件。
